# Valley Auto Transportation Landing Page

A responsive single-page marketing site for Valley Auto Transportation, focused on customers in East Valley, AZ. The page highlights services, coverage, process, testimonials, and a quote request form.

## Local preview
1. From the project root, start a simple static server (replace 8000 if the port is in use):
   ```bash
   python -m http.server 8000
   ```
2. Open your browser to `http://localhost:8000` to view the page.
3. Stop the server with `Ctrl+C` when you are done.

## Project files
- `index.html` – page structure and content.
- `styles.css` – layout, theming, and responsive styles.
- `script.js` – mobile nav toggle and client-side form validation feedback.
